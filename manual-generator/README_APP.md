# 安装说明工作台

这是可以在本机运行的通用前后端应用：输入 STP / STEP，起草可修改的安装步骤，在三维模型中选视角、调整爆炸图，逐步生成 SVG，最后沿用你提供的原两页 PDF 模板交付。

前端、Python 后端与三维查看器依赖均包含在应用目录中，同源访问，不需要 Node.js、npm 或单独启动前端。依赖清单在 `requirements.txt`；第三方许可见 `THIRD_PARTY_NOTICES.md` 和 `frontend/vendor/`。

## 启动

准备 Windows 与 **64 位 Python 3.11 或 3.12**，完整解压应用包，然后双击 **启动.cmd**。首次运行在应用目录创建 `.venv` 并安装依赖；之后复用环境，打开 <http://127.0.0.1:8765/>。首次准备依赖需要联网，准备完成后模型处理和出图在本机执行。

保持启动窗口运行；关闭服务时按 `Ctrl+C`。启动服务本身不会重新生成已有项目的插图或 PDF。

在 PowerShell 中也可以运行：

```powershell
.\start-app.ps1
```

指定已有 Python 环境，依赖已齐备时直接复用：

```powershell
.\start-app.ps1 -Python "D:\PythonEnvs\manual\Scripts\python.exe"
```

如果指定的是普通 Python 且依赖未齐备，脚本会在应用目录准备 `.venv`，保留全局 Python。指定的虚拟环境若缺少固定依赖，则在该环境安装 `requirements.txt` 的版本。需要主动修复依赖时使用 `-InstallDependencies`。

注册已有说明书项目，并选择数据位置或端口：

```powershell
.\start-app.ps1 -Python "D:\PythonEnvs\manual\Scripts\python.exe" -RegisterProject "D:\ManualProjects\ProductA" -DataDir "D:\ManualData" -Port 8767
```

已有项目目录需要包含 `steps.json`、`source.json` 和 `inventory/` 等完整工程数据。注册会直接使用该目录，之后的编辑会写入该项目；不复制或重新导入模型。可传多个目录：`-RegisterProject "D:\ProjectA","D:\ProjectB"`。相对参数路径以运行命令时的目录为基准；默认数据位置是应用目录的 `app-data/`。

只检查环境和应用文件、不启动服务或生成文件：

```powershell
.\start-app.ps1 -Python "D:\PythonEnvs\manual\Scripts\python.exe" -CheckOnly
```

`-NoBrowser` 启动服务但不自动打开浏览器。端口被占用时脚本会提示，换用 `-Port` 即可。

## 日常使用

V7 工作台分为“步骤与插图、安装单元、多语言、模板与交付”四个入口。安装单元可以重命名、标记预装或待安装、按源实例拆分、合并；未绑定模板的安装动作可以增删、重排、选择多个参与单元。CAD 分支和几何体积不能作为实际安装先后的事实。最终模型总览独立于印刷步骤，不增加原两页模板的步骤数。

“多语言”支持中文原文与英、德、法、西译文逐条对应、编辑、核对。无外部翻译服务时只套用完整匹配的本地表述，其他内容保留待填写；通用 AI 翻译服务的可选配置见 README.md。绑定模板时会读取可翻译文字及来源摘要，译文导出还须校准文字区域。英文示例已按 E301 原模板校准；其他模板需明确校准，不能直接沿用它的坐标。

普通原模板 PDF 保留原中文字；语言 PDF 在同一模板的校准文字区替换译文。缺译、规格不一致、区域溢出会阻止导出；未经人工核对的译文只能输出草稿。换 STP、改原文、换模板后旧译文及导出凭据失效。界面保存的未提交草案另有配置基线核对，远程配置已变化时保留为可下载冲突稿，不自动覆盖新项目。

1. **新建项目并上传 STP。** 即使没有旧说明书，也可以起草总成分组、连接候选和步骤。CAD 层级、距离和几何指纹提供线索；安装顺序与总成边界始终是待修改、待确认的建议。
2. **检查步骤和三维模型。** 拖动选择清楚的观察角度，调整本步分离距离与方向。需要展示内部连接时可明确选择临时隐藏的源实例并记录原因，最终总览恢复显示。
3. **逐步出图。** “仅生成这一步”只重绘选中步骤的主图和局部图，不重绘整套、不生成 PDF。处理期间保留上一版图片；未对应当前配置的图片标记为过期，不作为确认或导出的当前结果。调整后自动预览可以关闭。
4. **绑定原两页模板。** 上传你的 PDF，为每个步骤校准旧图遮盖区、SVG 放置区和对应关系，避开编号与文字。可下载槽位配置供同一模板复用。模板绑定后保留原步骤文字、顺序和图槽对应；改变步骤数量或含义时要重新校准。
5. **检查并交付。** 每步图片对应当前配置后，包装同事核对、修改并确认即可，无额外审批流程。导出 PDF 是单独操作，保留原封面和图槽以外的文字、排版与图形，只替换已校准的步骤图；每步 SVG 和步骤配置也可单独下载继续排版。

“自动生成全部步骤图”适合首次形成一套图稿；后续视角、显隐或分离调整使用单步生成。完整 STP 导入、距离计算和隐线出图可能需要等待；后台任务状态会显示进度。

三维预览支持左键自由旋转（包括翻转和滚转）、右键平移、滚轮缩放。右上角的红 X / 绿 Y / 蓝 Z 辅助随视角转动；点击轴端点或下方的 ±X、±Y、±Z 可以从相应模型坐标方向观察。“左转/右转 15°”调整画面转正，“居中显示”找回模型，“重置视角”恢复当前步骤保存的视角。辅助、转正和轴向切换只改变预览；点击“采用当前视角”才保存到步骤，XYZ 不进入说明书插图或 PDF。

## 几何与换版边界

- 插图使用当前 STP 中的真实几何，通过 CAD 投影与遮挡计算生成 SVG，**不使用 AI 补画零件**。文件中没有网布、脚托、孔或螺丝时，不主动补造。
- 连续面或实体参与遮挡；实际孔洞可能透视；只有轮廓线不能提供完整遮挡面。若网布与框架没有可单独选择的源实例，不能直接只隐藏网布，需先建立可追溯的分离表示。
- 爆炸距离和箭头是展示与复位示意，不证明插入方向、运动无碰撞或紧固方式。包围盒评分只用于提出可编辑视角，不能保证连接细节准确可见。
- 上传新 STP 作为新版本后，只依据新模型起草；旧对应关系和确认先失效。几何比较会提出复核线索，不能保证自动沿用，重名也不作为实例匹配依据。
- 已有人工配置可以作为明确匹配源版本的配置继续使用，不能当作自动识别效果的证明。重复几何或近邻合并建议需人工选择；不自动删除、合并或隐藏源几何。

## 保存和移交

`app-data/` 保存项目登记、上传文件与新建项目的版本数据；注册的外部项目保留在原目录。编辑和出图的旧版本进入项目历史目录，当前模型缓存与实例身份绑定源 STP 摘要。移交时复制完整项目或完整数据目录，并保留原模板文件；独立 SVG 与配置用于后续排版。

应用包可解压到新目录。已有工程含本地路径引用；换机器或改变数据位置时，使用新的 `-DataDir` 登记迁移后的项目目录，重新选择原模板并导入保存的槽位配置，使引用对应新的文件位置。保留原路径时可继续使用原登记数据。

应用当前只监听 `127.0.0.1`。这套启动入口面向本机使用，关闭浏览器不会停止后端服务。
